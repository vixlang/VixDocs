# 发布说明

## v0.3.0 (2026-06-07)

### 新特性

#### 轻量级 Owner 系统
- 编译期所有权和借用检查
- 非 Copy 值的所有权转移
- 独占可变引用和共享不可变引用
- 使用后移动检测
- 悬垂局部引用检测
- 复制类型推断
- 语句级临时借用作用域

#### 新引用语法：`ref` 和 `mut ref`
- `ref value` 创建不可变共享借用
- `mut ref value` 创建可变独占借用
- 同一语句中允许多个不可变借用
- 可变借用不可重叠
- 临时借用语句结束后释放

#### 类型系统增强
- `usize` 成为认别类型关键字
- 单元类型 `()`
- 前缀逻辑非运算符 `!`
- 枚举定义支持前导 `|`

#### Match 增强
- 支持函数调用作为匹配条件：`match choose(1) { ... }`
- 支持单行分支体：`Some(v) -> print(v)`

#### 其他
- 复合赋值支持泛 lvalue（成员访问、索引、解引用）
- 多目标文件链接：`vixc a.o b.o -o prog`
- 字符串拼接空指针安全处理
- 全局动态数组 `push` 写回修复

### 内部变更

- 新增 `src/Ownership/Ownership.cpp`
- 新增 `include/ownership.h`
- 编译流水线：类型检查 → 所有权检查 → 代码生成
- 旧 `&` 引用语法由 `ref`/`mut ref` 替代

### 兼容性说明

不包含：生命周期标注、完整 NLL 分析、Pin/Unpin、Drop 检查、自引用结构体。
