# Vix Language Support

为 Vix 语言提供核心语言支持，包括语法高亮、智能代码补全（IntelliSense）和实时错误诊断提示。

## Features

本扩展为Vix语言提供了完整的开发支持，包括：

- **语法高亮**: 根据Vix语言的语法规则对代码进行彩色标记
- **智能代码补全(IntelliSense)**: 提供变量、函数、类等上下文相关的自动补全建议
- **实时错误诊断**: 在编写代码时即时检测并标出语法错误和潜在问题
- **代码折叠**: 支持基于缩进或语言结构的代码块折叠
- **括号匹配**: 自动高亮显示匹配的括号对
- **代码片段**: 预设常用代码模板，提高编码效率

## Requirements

无需额外安装依赖项。此扩展完全独立运行。

## Extension Settings

本扩展支持以下VS Code设置:

- `vix.maxNumberOfProblems`: 设置报告的最大错误数（默认100）
- `vix.enableLinting`: 启用/禁用代码风格检查（默认启用）

You can author your README using Visual Studio Code. Here are some useful editor keyboard shortcuts:

* Toggle preview (`Shift+Cmd+V` on macOS or `Shift+Ctrl+V` on Windows and Linux).
* Press `Ctrl+Space` (Windows, Linux, macOS) to see a list of Markdown snippets.
